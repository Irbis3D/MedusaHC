# Base parts

This folder contains the stationary hotend dock components and the related cleaning, priming, PTFE, and wire-management parts.

- `Base_Bin_Main V-Front.stl` and `Base_Bin_Main V-Back.stl` are layout-specific variants.
- `Base_Mount_Main.stl` and `Base_Mount_Plate.stl` are common mounting components.
- `Nozzle_Close_Clean_Main.stl`, `PTFE Cleaner.stl`, and `Side PTFE Holder.stl` belong to the cleaning and filament-guiding system.
- The wire-holder files provide alternatives for the listed fitting combinations.

Use the STEP assembly to confirm the selected variant, orientation, and required quantity for the chosen number of tools.
