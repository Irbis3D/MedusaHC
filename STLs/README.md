# Printable parts

This folder contains the printable MedusaHC V0.2 parts, organized by subsystem.

The supplied layout-specific mounts are currently designed for a **Duender with MGN9H rails on the XY axes**. An MGN12H installation requires the system to be raised slightly and the mounting geometry to be checked. Do not treat the MGN9H mounts as direct MGN12H replacements.

- `Base` — dock bases, bins, cleaning/priming parts, and cable/PTFE holders.
- `Feeder` — hotend-side feeder and servo-opening mechanism.
- `Hotend` — alternative printable hotend bodies.
- `Toolhead` — moving toolhead, extruder body, and MGN9H carriage mounts.
- `SexBall Mount` — printable parts for a SexBall-style contact calibration sensor.
- `V-Front Mounts` — layout-specific mounts for docks installed in front of the print area.
- `V-Back Mounts` — layout-specific mounts for docks installed behind the print area.

The V-Front and V-Back layouts share the common Base, Feeder, Hotend, and Toolhead parts. Select the layout-specific base and mounting parts required by the chosen arrangement.

The SexBall mounting parts are retained from the previous public release. Verify their compatibility with the selected contact sensor and printer geometry before printing.

Use the full STEP assembly as a visual reference. Verify quantities, orientation, clearances, hardware, and support requirements before printing a complete set.

For V-Front, the standard Duender front mounts can be retained by using the adapters from the Duender repository, or replaced with the included GN500 V-Front mounts. For V-Back, read the dedicated folder README before printing: the X axis, rail side, and belt path must be reversed.
