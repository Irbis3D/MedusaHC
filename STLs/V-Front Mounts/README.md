# V-Front mounts

These left and right **MGN9H** mounts are used when the MedusaHC docks are installed in front of the print area. The design with an opening for the front profile was contributed by **GN500**.

V-Front provides room for more tools and can be convenient when adapting MedusaHC to other CoreXY layouts. The supplied STEP reference demonstrates that five tools can fit, while the supplied configuration and slicer preset use four tools.

There are two supported approaches for a Duender front installation:

- keep the standard Duender front mounts and use the printable MedusaHC adapters from the [Duender repository](https://github.com/Irbis3D/Duender);
- replace the standard mounts with the GN500 V-Front mounts in this folder.

GN500 has also published an MGN12H version on Printables. The files in this folder are the MGN9H version. For V-Front, the X rail and belt routing remain in the standard Duender orientation; no other kinematic changes are required.

Set `variable_tools_direction: 1`, enter the real dock coordinates, and place printer parking positions safely away from the front docks.
