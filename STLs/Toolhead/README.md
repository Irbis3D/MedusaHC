# Toolhead parts

This folder contains the moving MedusaHC toolhead components.

- `Extruder Main.stl` — main moving extruder/toolhead body.
- `MGN9H Mount Main.stl` — standard MGN9H carriage mount.
- `MGN9H Mount EDDY ADXL.stl` — MGN9H mount variant for the Eddy/ADXL arrangement shown in the project.

Choose the carriage mount that matches the installed sensors and verify probe offsets and cable clearances after assembly.
