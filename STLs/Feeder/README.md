# Feeder parts

This folder contains the printable parts for the hotend-side feeder and its servo-assisted opening mechanism.

The set includes the feeder body, lever, cover, opener, servo mount, and MG90S-related parts. These components are repeated for each installed tool as required by the assembly.

The mechanism must move freely without excessive play. Print quality, pin alignment, spring selection, and surface finishing directly affect reliable opening and closing. Use the STEP assembly to confirm orientation and hardware placement.
