# STEP assembly

`MedusaHC V0.2.step` is a visual and mechanical reference for both supported layouts.

The assembly demonstrates five tools in the V-Front layout and four tools in the V-Back layout. The supplied Klipper configuration and slicer examples are configured for four tools.

Verify the actual printer geometry, clearances, mounting positions, and tool count before manufacturing parts from this assembly.

## Experimental feeder assembly

`MedusaHC_Feeder_Lever_MOD.step` contains the new lever-driven feeder as a separate assembly. This experimental feeder is not yet included in the main `MedusaHC V0.2.step` assembly.

The printable files in `STLs/Feeder` have already been updated to this new feeder version. The previous feeder parts are no longer provided as separate STL files; users who need the old design can obtain them from the full `MedusaHC V0.2.step` assembly, where the previous feeder is still included.

The new version is currently being tested. If it proves reliable, it will replace the current feeder as the main version and will be added to the full MedusaHC STEP assembly.
